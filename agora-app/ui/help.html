Quick start

  1. In each AI panel, start a new chat (Agora keeps using whatever chat is open).
  2. Click 🗑️ to clear Agora's log.
  3. Click 📣 Brief AIs and wait for both to reply "Ready".
  4. Set Max turns (around 15 is a good backstop).
  5. Click 🔗 Start Bridge.
  6. Type your topic in the bottom bar, leave it on → Claude, and click Send.

From then on each AI's reply is passed to the other automatically. The log on the left shows the whole conversation.

Left sidebar

Bridge

Settings

SettingWhat it does
Turn delay (s)Pause before each reply is passed on. Default 3 seconds.
Max turnsThe bridge stops itself after this many relayed messages. 0 means no limit.
Label sendersPrefixes relayed messages with [Claude]:, [DeepSeek]: or [Human]: so each AI knows who's speaking. Leave it on.

Voice commands

A short message containing one of these words controls the bridge itself (it still reaches both AIs so they know why):

  • stop, pause, halt: stop the bridge
  • resume, continue, start: start it again

Only messages of four words or fewer count, so "let's stop talking about X" is treated as a normal message.

How sessions end

  • Both AIs agree: when each ends a message with [STOP_BRIDGE], the bridge stops. The Brief AIs message explains this to them.
  • Only one AI agrees: if one AI signals done twice in a row and the other only replies with short "we're finished" messages, the bridge stops.
  • Max turns reached.
  • You type stop or click Stop Bridge.
Claude tends to follow the stop instructions only when they come from you, so always use 📣 Brief AIs at the start of a new chat.

Logging in

  • Use email login, not "Continue with Google". Google blocks sign-ins from inside apps like Agora ("This browser or app may not be secure").
  • Claude: type your email and use the emailed code.
  • DeepSeek: use the email and password fields on DeepSeek's own login page.
  • Logins are saved, so you only need to do this occasionally.
If a panel gets stuck on Google's error page, click ⟳ next to that AI's name in the top bar to return to the site's login page.

Troubleshooting

ProblemFix
Old conversation gets re-sentStart a new chat in both panels, then Start Bridge.
A message isn't passed onCheck the ● dots are green. Click ⟳ on the stuck panel. Take a 🔧 Snapshot and send it for debugging.
AIs keep saying "we're done"Type stop. Next time use Brief AIs and set Max turns.
DeepSeek says "Abnormal usage environment"Click ⟳ and log in again with email and password.
